# Sprint4（2026-10-30）：搜索语义修正与浅 TT 排序复用

**基线**：`head_engine/` 快照本轮起从 `42980e5` 刷新为 `78396b4`（sprint3 定稿提交，
当时 git HEAD）。刷新后 OrderProbe 验证：WORK 关闭新开关与 HEAD 快照在
规则0 开局 / 规则2 中局定点上**逐位一致**（节点、根分、PV 全同）。

**候选**：工作区引擎 = `78396b4` + 两项独立改动（初始均以默认关闭的开关引入）：

- **A 臂 `quiescenceStrictCapture`**：静默搜索在强制提子节点（`ACTION_CAPTURE`）
  不做 stand-pat——旧行为等价于允许"不提子"的非法停着（静态分截断或全部提子
  较差时返回静态分）。语义正确性由 `SearchRegression` 白盒定稿。
- **B 臂 `ttMoveFromShallow`**：浅层 TT 条目（`storedDepth < depth`）仍解出最佳
  走法作排序提示；分值/窗口/截断仍要求深度足够，浅条目不刷新代数、不计入
  `ttHits`。注意它不是纯排序改动：TT 加成参与 `<2400` 的 futility/LMR 资格
  判定，等深根分允许小幅漂移。
